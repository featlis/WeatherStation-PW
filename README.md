# 『並行世界の気象台』 (Aetheria Observatory) v5.0

> **実在する世界のリアルタイム気象データを、無数の異星（Exoplanets）の幻想的な風景と自然環境音響にリアルタイム変換するWeb観測所。**

---

## 🌌 主な機能と進化 (Exoplanet Suite v5.0)

### 🪐 1. 3Dホログラム地球儀 ＆ 宇宙スカイ特徴
観測地点ごとに、独自の惑星名・惑星分類コード（`EXO-701-β`等）・表面重力・大気組成・天体スカイ特徴が自動生成・セッション保持されます。
- **ホログラム惑星儀 (3D Hologram Wireframe Globe)**: HUD内にリアルタイム自転する惑星球体と緯度経度グリッドを投影。
- **大気フラックス・オシロスコープ (Atmospheric Flux Waveform)**: 気圧・風速・霊脈密度にリアルタイム追従するサイバーオシロスコープ波形モニター。
- **巨大惑星リング (Planetary Rings)**: カッシーニの間隙、内側クレープ環、惑星の影を投影した高精度3Dリング。
- **空に浮かぶ巨大ガス惑星 (Gas Giant with Moon)**: 木星型多層対流バンド、大赤斑サイクロン、公転する2つの衛星。
- **連星系・二重恒星 (Binary Suns)**: 太陽コロナフレア、プロミネンス、アナモルフィック・レンズフレア光芒。
- **超高速回転パルサー (Pulsar Magnetar)**: 天空を光速スイープする相対論的ジェット光線とシンクロトロン衝撃波環。
- **深宇宙星雲帯 (Deep Cosmic Nebula)**: スクリーン合成による幻想的な宇宙塵の裂け目と原始星群。

### 🏔️ 2. 16大モジュラー・プロシージャルバイオーム (高精細レイヤー描画)
1. **星間摩天楼 (Megalopolis)**: パララックス多重超高層ビル群、光窓マトリクス、航空ビーコン、流れる空中交通車両の光跡。
2. **霊光草原・巨大霊樹 (Plains & Spirit Tree)**: 風速に波打つ数百本の草葉、光脈が走る巨大霊樹、舞い散る発光花弁。
3. **結晶海岸・波光 (Coast)**: 打ち寄せるバイオルミネセンス発光波、濡れた砂浜の反射、水晶灯台のサーチライト。
4. **浮遊列島・天球神殿 (Archipelago)**: 荒削りの岩盤根、天空へ注ぐ発光滝、古代ギリシャ風天球神殿、浮遊オベリスク。
5. **極氷晶界・氷尖塔 (Glacier)**: プリズム屈折するファセット氷尖塔、ダイヤモンドダスト粒子。
6. **星核溶岩・発光カルデラ (Plasma Caldera)**: マグマ亀裂、沸騰するプラズマ火口湖、立ち上る地熱噴煙。
7. **巨晶の森・クォーツ尖峰 (Crystal Forest)**: 六角柱クォーツ群、内部を走るエネルギーパルス、ピエゾ共鳴。
8. **星屑砂漠・古代環状遺跡 (Desert Ruins)**: 風紋砂丘、スターゲート型古代ポータル環、浮遊モノリス群。
9. **深淵発光サンゴ礁 (Deep Abyss Reef)**: ゆらめく生体触手群、先端発光バルブ、深海マリンスノー。
10. **太陽受光塔・集光アレイ (Solar Spire)**: 多重回転集光リング、天空を穿つ光子ビーム、地表エネルギーグリッド。
11. **星雲峡谷・大断崖 (Nebula Canyon)**: 両側にそびえ立つ大断崖、峡谷底を流れる発光星雲の河。
12. **発光茸の森・胞子樹林 (Mushroom Grove)**: 半透明の蛍光傘、放射状ヒダ、落下する胞子粒子。
13. **幽霊沼沢・水鏡湿原 (Ethereal Swamp)**: 星空を鏡のように反射する水面、光る睡蓮パッド、蓮華の花。
14. **天空要塞・幾何学モノリス (Floating Citadel)**: 反重力回転する多重磁気リング、ファセット八面体メガフォートレス、格納庫誘導光。
15. **溶融プラズマ海・紅蓮波 (Lava Ocean)**: 赤熱する超高温プラズマ波、漂う玄武岩地殻。
16. **極光ツンドラ・発光苔原 (Aurora Tundra)**: 永久凍土平原、オーロラと共鳴明滅するバイオルミネセンス苔。

### 🎶 3. リアルタイム・オーディオ・シンセサイザー (Web Audio API)
- **ライブ・スペクトラム・アナライザー (Live Audio Spectrum)**: HUD内で再生音響の周波数帯域をリアルタイム描画。
- **恒星瞑想シンセパッド (Celestial Ambient Pad)**: バイオームの調和音（リディアン／ペンタトニック）に自動変調する穏やかな持続和音。
- **10チャンネル自然環境音響**: 雨粒、鳥のさえずり、風草、波のさざなみ、星光コオロギ、水晶ベル、砂嵐、せせらぎ水音、チャイム。
- **プロシージャルUI効果音**: ボタン操作音、ワープ次元跳躍音、528Hz Solfeggio集中ベル音。

### 🌌 4. 銀河観測アーカイブ (Planet Codex) ＆ 時空共鳴シミュレータ
- **銀河観測アーカイブ**: 発見した惑星を自動記録（`localStorage`）。いつでも過去の惑星へ再跳躍可能。
- **時空共鳴シミュレータ**: 天候、バイオーム、風速、気温を手動でスライダー変更し、風景のリアルタイム変容を実験可能。
