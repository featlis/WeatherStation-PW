# 『並行世界の気象台』 (Aetheria Observatory)

> **実在する世界の気象データを、無数の異星（Exoplanets）の幻想的な風景と自然音響にリアルタイム変換するWeb観測所。**

---

## 🌌 新機能：異星気象＆10大バイオーム・コンビネーション (Exoplanet Suite)

### 🪐 1. 地点ごとに異なる別惑星・天体スカイ特徴
観測地点ごとに、独自の惑星名・惑星分類コード（`EXO-701-β`等）・表面重力・大気組成・天体スカイ特徴が自動生成・セッション保持されます。
- **巨大惑星リング (Planetary Rings)**: 空を斜めに横切る多層構造の発光リング。
- **空に浮かぶ巨大ガス惑星 (Gas Giant with Moon)**: 縞模様がうごめく巨大惑星と公転衛星。
- **連星系・二重恒星 (Binary Suns)**: 黄金の主星と菫色の伴星。
- **パルサー光線 (Pulsar Beam)**: 高速回転する中性子星の指向性放射。
- **深宇宙星雲帯 (Deep Cosmic Nebula)**: スクリーン合成による幻想的な星雲の裂け目。

### 🏔️ 2. 10種類のモジュラー・プロシージャルバイオーム
1. **星間摩天楼 (Megalopolis)**: 幾何学的な光窓と避雷針ビーコンが輝くサイバーハイヴ。
2. **霊光草原 (Plains)**: 風速に合わせて波打つ草葉と巨大霊樹。
3. **結晶海岸 (Coast)**: 周期的な発光波と水平線。
4. **浮遊列島 (Archipelago)**: 重力浮力で上下に揺らぐ島々と天球神殿。
5. **極氷晶界 (Glacier)**: プリズム屈折する氷尖塔群。
6. **星核溶岩・発光カルデラ (Plasma Caldera)**: 脈動するプラズマコアと地熱噴煙。
7. **巨晶の森 (Crystal Forest)**: ピエゾ発光する巨大クォーツ尖峰。
8. **星屑砂漠・古代遺跡 (Desert Ruins)**: 流砂の砂丘と古代環状オベリスク。
9. **深淵発光サンゴ礁 (Deep Abyss Reef)**: ゆらめく生体発光触手群。
10. **太陽受光塔 (Solar Spire)**: 恒星エネルギーを集束する受光アレイ。

### 🎲 3. ランダム惑星探索 (Random Planet Warp)
- ヘッダーの `🎲` ボタン、またはキーボードの <kbd>W</kbd> キーを押すことで、世界中の観測所プール（アタカマ砂漠、スヴァールバル、ガラパゴス、カイロ、ラサ、トロムソ、ウシュアイア等40+拠点）から瞬時にランダム跳躍。

### 🎶 4. 100%ドローンフリー・豊かな有機的環境音響 (10 Sound Channels)
低周波の機械音や不快な唸り（ドローン）を完全排除した、澄んだ自然音響：
1. **雨音・水滴 (Rain & Droplets)**
2. **天球鳥のさえずり (Celestial Birdsong - FM変調)**
3. **風と草原のそよぎ (Wind & Grass Rustle)**
4. **波のさざなみ (Ocean Surf)**
5. **星光コオロギ・虫の音 (Astral Crickets / Night Insects)**
6. **水晶共鳴ベル (Quartz Crystal Bells)**
7. **星屑砂漠風 (Desert Sand Breeze)**
8. **せせらぎ水音 (Water Stream)**
9. **着地クリスタルチャイム (Pentatonic Chimes)**
10. **瞑想・集中ベル (528Hz Solfeggio Focus Bell)**

## ⌨️ 操作ショートカット
| キー | 機能 |
| :--- | :--- |
| <kbd>W</kbd> | **ランダム惑星探索（次元跳躍）** |
| <kbd>画面クリック</kbd> | **重力波ショックウェーブ & チャイム** |
| <kbd>P</kbd> | **惑星観測絵葉書（スナップショットPNG）保存** |
| <kbd>F</kbd> / <kbd>Space</kbd> | **全画面観察モード（HUD非表示）** |
| <kbd>M</kbd> | **環境音響ミュート切り替え** |
| `🎛️ 音響ミキサー` | **各環境音の独立音量スライダー** |
| `START` | **25分集中 / 5分休憩 ポモドーロタイマー** |
